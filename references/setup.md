<setup>
**A 30-minute first session.** Have email inbox access, a password manager and an authenticator app available. No posting, subscription or developer account is needed for the manual reading workflow.

1. **Create and secure — 7 minutes.** Open https://x.com and create an account with an email the user controls. Verify it; choose a recognizable handle and a simple bio. Skip contact uploads and broad suggested follows. In Settings and privacy → Security and account access → Security → Two-factor authentication, configure an authenticator app or security key and store the recovery code privately. Never ask the user to paste that code into chat.
2. **Quiet settings — 5 minutes.** In Notifications, disable recommendation push/email, retain security notices and keep Quality filter on. Under Privacy and safety, review discoverability/contact syncing and restrict unsolicited direct messages. In Mute and block → Muted words, start with three distracting phrases and apply them to Home and notifications. Muting does not filter search results.
3. **Choose people — 8 minutes.** Read `accounts.md`; start with its 12-person table and let the user inspect each profile. Select Following on Home. For you includes recommendations; use it deliberately for discovery rather than the daily starting page. Following can still show reposts and ads.
4. **Create reading tabs — 7 minutes.** Open Lists → new List; create AI-native services, Enterprise AI and Applied AI as Private. Add starter handles using Manage members or a profile's Add/remove from Lists menu. Pin each List. A List member need not be followed. Add the other five topics over the week.
5. **Save the first useful post — 3 minutes.** Open a post, choose Bookmark and locate it again through Bookmarks. Ask what it changes about a buyer question, delivery choice or business assumption. Write that implication beside the original URL and close X.

If the user is locked out, use X's account-recovery flow rather than reusing someone else's credentials. If a profile is unavailable, leave it out and pick another relevant person with current evidence. If Lists is hidden, inspect More or the profile navigation; the menu label can differ by device. Do not claim to have changed settings unless the user confirms the screen or an authorized tool verifies it.
</setup>
