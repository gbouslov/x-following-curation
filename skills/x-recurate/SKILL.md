---
name: x-recurate
description: Refreshes goals, graph coverage and account selections in a monthly feed review. Use when a feed becomes noisy, the user's work changes or a monthly review is requested.
---

<objective>
Keep the feed aligned with changing work, using the user's actual reading value rather than follow-count reduction. Retain useful low-volume people and avoid repeated follow/unfollow churn.
</objective>
<quick_start>
Read local/goals.md, local/session.md, local/reading.md and existing apply receipts. Use x-goals for changed intent, x-pull-graph for fresh snapshots, x-classify for judgments, x-discover for gaps and x-apply for any approved actions. Never schedule this automatically from a date alone.
</quick_start>
<process>
1. Spend five minutes reviewing the last month's saved posts and decisions. Which people produced useful work? Which questions remain unanswered? Ask about changed goals and pinned relationships; old assistant recommendations are not current user commitments.
2. With a renewed explicit read budget, snapshot following/followers and compare by numeric ID with the previous snapshot. Distinguish kit changes from external/intervening changes; do not attribute every count movement to this tool. If either snapshot is incomplete, report additions/removals only for the comparable known set.
3. Reassess new, noisy or stale accounts from recent original posts and maintain one disposition per current following ID. Sparse data stays review. Do not reverse an approved action just because its score moved; read prior reasons, receipts and the user's goals. The helper refuses repeat writes to a prior target except through a reviewed undo plan; do not clear state to evade that protection.
4. Discover only the uncovered topics, with a smaller capped search. Show a review table of proposed removals/additions, useful counterviews and unchanged pins. Use ten or fewer actions as a reviewable batch cap, never a monthly quota. Run x-apply only after fresh exact-list approval.
5. Record local/monthly/YYYY-MM.md: goals version, before/after snapshot counts and coverage, useful saved-post examples, actual changes versus proposals, settled cost and one adjustment to the reading routine. Preserve prior reports. Offer the next monthly date without installing a background job.
</process>
<success_criteria>
The user can see whether the feed helped real decisions, what changed and why. Counts reconcile with snapshots and receipts, goals are current, no automatic churn occurred, and every external action had its own approval.
</success_criteria>
